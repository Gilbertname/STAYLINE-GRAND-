# STAYLINE GRAND 2.5｜模擬線上結帳及學生證人工審核

## 本次新增

1. 顧客訂房成功後直接進入「結帳頁」。在「我的訂單」也可以點「前往付款」。
2. 付款方式：模擬信用卡、模擬銀行轉帳、到店付款。**所有線上付款均為本機模擬，不接入第三方金流，不收集信用卡號、CVV、不扣款。**
3. 模擬付款會在本機 SQLite 的 `payments` 表留下測試記錄；已結清的訂單不允許重複付款。
4. 標準客房學生九折申請者須提供與會員一致的姓名、就讀學校及學生證有效期限。**必須到櫃檯出示本人實體有效學生證**，管理員經人工查驗才可核准並按學生價完成模擬付款。
5. 管理員登入後前往 `http://127.0.0.1:8100/student-review`，審核學生證。審核拒絕時，訂單會回復原價，並可按原價進行模擬付款。
6. 豪華客房和行政套房依然不適用學生九折。

## 更新方式

推薦在新資料夾解壓完整 ZIP，再將舊系統停止後的 `stayline_grand.db` 複製到新版資料夾。請先另存一份資料庫備份，且不要覆蓋掉原本的系統。新表 `student_verifications` 會自動建立，不會刪除舊資料。

> **舊版已存在的學生折扣訂單：** 因舊版沒有保存學生證審核狀態，升級後這類未付款訂單會需要額外核對。建議用新版重新建立測試訂單，不要直接拿舊訂單測試學生模擬付款。

## 操作演示

顧客：註冊／登入 → 搜尋房間 → 預訂 → 勾選學生九折（標準客房限定）→ 輸入姓名、學校、有效日期 → 建立訂單 → 結帳頁。

櫃檯：顧客現場出示有效學生證 → 管理員開啟 `/student-review` → 核對姓名與有效期限 → 核准／拒絕。

顧客：在「我的訂單」按「前往付款」→ 選擇模擬付款或到店付款 → 顯示結果、更新餘額。

## 安全提醒

這是學習作品，不是正式的商業支付系統。不可要求他人輸入真實銀行卡資料、不可使用它來收取真實款項。證件僅現場查驗，不保存證件照片或學號。
