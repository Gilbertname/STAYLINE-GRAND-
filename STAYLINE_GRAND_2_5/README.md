# STAYLINE GRAND｜全方位飯店管理系統（獨立新版）

這是一套**新的、可在本機運行的完整教學示範專案**，以你提供的 SUNSET HEAVEN《Project Documentation》當作功能需求參考，採用原創介面實作，不是它的 Java 原始碼、資料庫或圖片複製品。也不會修改 STAYLINE 舊版。

## 一、安裝與啟動（Windows 11）

你已安裝 Python 3.14.10；此版**只使用 Python 標準函式庫**，不需安裝 Flask、MySQL、Node.js。若系統沒有 tzdata，也會使用台灣 UTC+8 固定時間作為後備。

1. 把 ZIP 解壓到新資料夾，例如 `Downloads\STAYLINE_GRAND_Complete`。
2. 進入解壓後的 `STAYLINE_GRAND_Complete` 資料夾，找到 `server.py` 與 `start_windows.bat`。
3. **雙擊 `start_windows.bat`**。不要關閉黑色視窗，否則網站會停止。
4. 在同一台電腦的 Chrome 開啟：
   - **管理員／員工後台：<http://127.0.0.1:8100/>**
   - **顧客訂房網站：<http://127.0.0.1:8100/guest>**
5. 第一次進入管理後台，建立**管理員帳號與至少 8 個字元的密碼**。資料庫會自動建立，並內建 12 間示範客房。
6. 日後使用時先雙擊 `start_windows.bat` 再開 Chrome。停止伺服器請在黑色視窗按 `Ctrl+C`。

如果不想雙擊，開啟這個資料夾的 CMD 並輸入：

```cmd
py server.py --port 8100
```

> **舊版可同時保留**：舊版預設 `http://127.0.0.1:8000` 和 `hotel.db`；此新版使用 `http://127.0.0.1:8100` 和 `stayline_grand.db`。帳號、訂單、客房資料與登入 Cookie **不互通**，也不需把舊版 `hotel.db` 複製過來。兩者彼此獨立。

## 二、依 SUNSET HEAVEN 文件延伸的功能

| 區域 | 功能 |
|---|---|
| 管理員 | 首次建立帳號／登入、營運總覽、客房管理（房價／房型／床型／容納人數）、房客、訂房、收款、報表 |
| 顧客 | 自行註冊、登入、查詢日期空房、預訂、查看訂單與帳單、取消未付款訂單、修改聯絡資料 |
| 櫃檯員工 | 房客與訂單、櫃檯收款、審核顧客入住／退房申請、回覆客服工單 |
| 房務員工 | 清潔房間狀態、接收或完成客房服務工單、上下班打卡 |
| 人事／管理員 | 建立員工與員工帳號、部門與班次、請假審核、培訓紀錄、薪資登記 |
| 客房服務 | 餐飲配送、洗衣、清潔、維修請求；完成後將有價服務計入訂單帳單 |

**與 SUNSET 文件的差異**：目前每張訂單只能訂一間房；示範金額使用新台幣 NT$；線上支付介面、電子錢包 QR Code、信用卡金流、薪資轉帳、員工自動計薪與真實通知整合均未接入。文件的 Java + MySQL 技術堆疊，此版用更易在 Windows 上執行的 Python + SQLite 取代。

## 三、三個身分、兩種登入頁

| 身分 | 進入地址 | 怎麼建立帳號 |
|---|---|---|
| 管理員 | `/` | 第一次打開後台設定 |
| 櫃檯／房務員工 | `/` | **由管理員**在「員工與權限」新增員工，然後建立員工登入帳號、選擇其角色 |
| 顧客 | `/guest` | 到顧客網站按「會員登入 / 註冊」自行申請 |

後台與顧客會員密碼各自獨立，且存取權限不同。櫃檯和房務角色不能管理薪資。

## 四、完整操作練習（建議照順序）

1. **管理員**首次建立帳號，進入「營運總覽」，看看客房和今日訂單。
2. 到「員工與權限」新增一位櫃檯員工、一位房務員工，並分別建立帳號。可試驗排班、請假和打卡。
3. 開另一個 Chrome 視窗進入 `/guest`，註冊顧客會員，選今天入住、明天退房、1 位大人，查詢可訂客房。
4. 點選「預訂這間」，送出訂房；換回管理員後台「訂房管理」，能看到顧客訂單。
5. 顧客到「我的訂單」申請入住。櫃檯到「入住／退房申請」點同意。**入住需符合日期且房間已清潔。**
6. 顧客入住後到「客房服務」新增餐飲／洗衣服務；房務在「客房服務」標示完成，訂單帳單即會增加服務費。
7. 櫃檯前往「收款紀錄」，記入足額示範款項；顧客申請退房，櫃檯審核同意後該房間變成「待清潔」。
8. 房務到「房務清潔」把房間標記為已清潔。顧客在「協助中心」留言，櫃檯在「顧客客服」回覆。
9. 管理員到「營運報表」查看訂房和收入統計；再去「排班與請假」「員工培訓」「薪資管理」體驗員工管理流程。

**防錯規則**：同一間客房在有重疊的住宿日期不可被重複預訂；未付清房費與已完成客房服務費不能退房。一般退房日不算住房夜晚，例如 11/16 退房、另一位顧客 11/16 入住不算日期撞期，但須先完成客房清潔。

## 七、常見問題

- **網頁「拒絕連線」**：請先雙擊 `start_windows.bat` 並保持黑色視窗開啟；確認網址是 `8100`，不是舊版的 `8000`。
- **找不到 Python**：開 CMD 輸入 `py --version` 確認 Python 已裝好。
- **8100 埠被占用**：先關閉之前開啟的新系統伺服器，再重新啟動；若需要手動改埠，執行 `py server.py --port 8200`，網址也改為 `8200`。
- **登入後發現空白**：按 `Ctrl+Shift+R` 強制重新整理；確認是在同一套新系統的 `8100` 網址。
- **密碼忘記**：此版沒有管理員自助密碼重設，請勿隨便刪除資料庫；先備份後再研究恢復方式。
- **想刪除所有展示資料重新開始**：停止系統，備份 `stayline_grand.db` 後移走該檔，下次啟動會重新建立空資料庫與 12 間示範客房。
