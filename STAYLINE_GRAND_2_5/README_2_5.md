# STAYLINE GRAND 2.5｜最新功能說明

本版本在 2.4 的全部功能上新增 **模擬線上付款** 與 **學生證人工審核**，詳細使用步驟請參閱 [VERSION_2_5_UPDATE.md](VERSION_2_5_UPDATE.md)。

在 Windows 11 的專案資料夾地址列輸入 `cmd`，執行 `py server.py`；管理員後台 `http://127.0.0.1:8100`、顧客網站 `http://127.0.0.1:8100/guest`、學生證審核 `http://127.0.0.1:8100/student-review`。

**請勿將模擬付款宣稱為真實收款。**
