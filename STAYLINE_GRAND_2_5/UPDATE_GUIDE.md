# STAYLINE GRAND 2.1 — 班次編輯修正版

更新內容：在「排班與請假 → 班次設定」新增「編輯」「刪除」操作，顯示已分配員工數。管理員可修改班次名稱與上下班時間；若班次已分配員工，不能直接刪除。

## 更新現有系統（保留原資料）
1. 在黑色 CMD 視窗按 Ctrl+C，停止 STAYLINE GRAND 伺服器。
2. 找到你正在使用的 `STAYLINE_GRAND_Complete` 資料夾，先備份其中的 `hotel.db`。
3. 將此修正包中的 `ops.js` 與 `hotel_modules.py` 複製到 `STAYLINE_GRAND_Complete`，同意取代同名檔案。
4. 回到原本的系統資料夾，在地址列輸入 `cmd` 後按 Enter，在黑色視窗輸入 `py server.py`。
5. 用瀏覽器開啟 http://127.0.0.1:8100 ，按 Ctrl+Shift+R 重新載入。
6. 以管理員登入，打開「排班與請假」，在班次右側按「編輯」即可。

注意：**只替換兩個程式檔**，不要覆蓋或刪除 `hotel.db`。

### 班次與員工排班的差別
- 本功能修改的是**班次範本**，例如早班 07:00–15:00。這會影響已選用這個範本的員工。
- 如需把特定員工改到另一個班次，使用「員工與權限 → 編輯員工 → 班次」。
- 按特定日期輪班（例如週一早班、週二晚班）的日曆尚未加入。
