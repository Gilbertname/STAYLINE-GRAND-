# STAYLINE GRAND 2.2 房型介紹／學生優惠升級版

## 更新內容
- 客房卡片顯示更詳細房型介紹、容納人數、床型與示範設備。新增「房型詳情」彈窗和入住規定。
- 顧客訂房時可勾選「學生示範 9 折」，頁面顯示原價、折扣與應付金額；後端會重新計算並永久記錄折扣。
- 顧客訂單中顯示已使用的學生優惠。
- 房間設備與優惠為專題模擬資料；非真實飯店承諾。學生證由櫃檯人工查驗，系統未進行身分自動驗證。

## 原有資料保留／安裝步驟
1. 停止目前 CMD 伺服器（Ctrl+C）。
2. **務必先備份原資料庫 stayline_grand.db**。
3. 推薦僅複製 `guest.js`、`guest.css`、`hotel_modules.py` 覆蓋現有同名檔案；不要覆蓋 `stayline_grand.db`。
4. 在原資料夾執行 `py server.py`；首次啟動時自動增設 discount_type、discount_amount 欄位，舊訂單不變。
5. 在顧客頁面按 Ctrl+Shift+R 清除瀏覽器快取。

## 注意事項
- 更改管理員後台中「已使用學生折扣」的訂單金額可能影響折扣紀錄；正式營運系統應另作折扣覆核及修改流程。
- 學生證需於入住時人工查驗；目前沒有自動核驗資格或自動補收差額功能。
- 不提供實際房況、照片、金流或實際學生優惠承諾。
